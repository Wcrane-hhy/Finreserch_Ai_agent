# data/reports —— 年报 PDF 放这里

## 为什么仓库里没有 PDF

年报 PDF 是上市公司的公开披露文件，**不是本项目的版权**，而且一份就有 7MB 左右，
不适合随仓库分发。所以 `.gitignore` 里排除了 `data/reports/*.pdf`。

RAG 相关的功能要跑起来，需要你自己放一份进去。

## 怎么拿一份（以中际旭创 300308 为例）

1. 打开 **巨潮资讯网** <http://www.cninfo.com.cn/>（深交所 / 上交所的指定披露平台）
2. 搜索框输入股票代码，例如 `300308`
3. 公告类型筛选「**年度报告**」，选 2024 年年度报告（全文，不是摘要）
4. 下载 PDF，放到本目录，文件名随意，建议保留可读性，例如：

```
data/reports/中际旭创 2024 年年报.pdf
```

## 放好之后建索引

```bash
python -m rag.rag_query --build
```

实测输出：**236 页 → 550 个 chunk → 550 × 512 维向量**，约 1 分钟，
落盘在 `data/vector_db/`（同样被 .gitignore 排除，属于可重建的生成物）。

这一步**只需跑一次**。只有两种情况要重跑：

- 换了 PDF
- 改了 `rag/chunker.py` 里的 chunk 参数

## 换一家公司

RAG 的检索范围就是本目录下的 PDF。换公司时：

1. 把新的年报 PDF 放进来（旧的可以留着，也可以删）
2. 删掉 `data/vector_db/` 重新 `--build`

当前版本**只入库了一份年报**，也不做跨文档去重，所以别把一堆 PDF 一起丢进来
还期待它自动分清谁是谁 —— 详见 README「已知限制」。
